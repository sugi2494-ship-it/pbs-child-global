# PBS 마케팅 팀 & 자동화 에이전시 운영 가이드

이 폴더와 `.claude/`는 이 리포(채팅방)를 **인스타·블로그 마케팅 팀**으로 쓰기 위한 설정이다.
팀원은 사람이 아니라 에이전트 7명이고, 클라이언트가 늘어나면 `clients/` 폴더만 추가하면 된다(에이전시 모드).

## 팀 구성
| 에이전트 | 역할 | 이렇게 부르면 된다 |
|---|---|---|
| marketing-director | 팀장. 목표·타깃 확정, 팀 배분, 실행안 통합 | "이번 달 마케팅 전략 짜줘" |
| competitor-researcher | 경쟁사·레퍼런스 계정 분해 | "이 계정 벤치마크해줘" + 스크린샷 |
| content-planner | 주간·월간 캘린더 | "다음 2주 캘린더" |
| reels-writer | 릴스 대본·캡션·해시태그 | "10/13 릴스 대본 써줘" |
| carousel-writer | 카드뉴스 장별 문구·디자인 지시 | "카드뉴스 8장" |
| blog-writer | 네이버 블로그 SEO 글 | "'어린이 강점 검사' 블로그 글" |
| performance-analyst | 인사이트 → KPI 표 → 다음 주 할 일 | "이번 주 성과 진단" + 인사이트 캡처 |

한 번에 전부: `/marketing-team <브리프>` (예: `/marketing-team 11월 자격과정 모집, 타깃 강사 지망생`)

## 폴더
```
marketing/
  brand/pbs-brand-brief.md     ← 팀 전체가 읽는 기준 문서. 숫자·톤·금지사항
  templates/                   ← 산출물 양식 6종 (벤치마크·캘린더·릴스·카드뉴스·블로그·주간리포트) + 클라이언트 브리프
  research/                    ← 벤치마크 결과
  calendar/                    ← 월별 캘린더와 원고
  reports/                     ← 주간 성과 리포트
  clients/<브랜드>/brief.md    ← 에이전시 모드. 클라이언트별 브리프
```

## 자동화 에이전시로 키우는 순서
1. **1단계 (지금~1개월) 자체 채널 운영**: PBS 계정으로 캘린더 2주 돌리고, 훅 유형별 조회·저장 데이터 쌓기. 산출물 양식을 현장에서 고친다.
2. **2단계 (2개월차) 패키지화**: `templates/client-brief-template.md`로 클라이언트 1곳 온보딩. 같은 팀이 `clients/<브랜드>/`에서 동일 공정 반복. 납품물 = 벤치마크 1 + 월 캘린더 1 + 원고 N + 주간 리포트 4.
3. **3단계 (3개월차~) 자동화**: 캘린더를 Notion DB로 옮기고, 주간 리포트를 Gmail로 자동 발송. Apify·Meta Ads·GA 연결 후 "경쟁사 분석하고 광고 성과 진단해줘" 한 문장으로 리포트 생성.

요금·계약 관련 문서는 모두 "제안 초안 — 확정 전 내부 검토용"으로 표시하고 법률 검토 후 사용한다.
