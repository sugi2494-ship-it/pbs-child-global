# 『컬러강점』 삽화·도표 계획

모든 그림은 같은 디자인 체계(마젠타 + 4엔진 컬러, Noto Serif KR 제목 / Noto Sans KR 본문)로 만든다.
출력: `node book-figures/export.js` → `out/<id>.pdf`(벡터, 인쇄용) + `out/<id>.png`(2400px, 검토·홍보용).
그림 안 문구는 원고 문장을 그대로 쓰거나 줄여 쓴다. 새 주장이나 수치를 넣지 않는다.

## 교구 연계
- 부록의 「열두 기어 사용 카드」(작동 범위·핵심·이럴 때·과열 신호·24시간 행동)를 10~13장 그림과 같은 틀로 카드 12장 + 엔진 카드 4장으로 만든다.
- 9-2 열두 기어 지도는 교구 판(보드)으로, 9-3 네 단계는 워크시트로 확장한다.
