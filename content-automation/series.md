# 「PBS 컬러강점 처방전」 주제 후보

매 편 구조는 같다: 공감 상황 4가지(번호) → 엔진별 원인 → 기어 처방 → 한 장 정리 → 번호 댓글 + 태그.
회의·직장에만 한정하지 않는다. 누구나 겪는 생활 장면을 우선한다.

## 후보 (위에서부터 우선, 사용하면 log.md에 기록)
- 다이어트가 3일 만에 끝나는 이유
- 답장이 늦는 이유 (친구 태그용)
- 부부 싸움이 커지는 방식
- 아이에게 잔소리가 터지는 순간 (학부모)
- 번아웃이 오는 방식
- 돈을 쓰는 방식 (충동 소비 유형)
- 여행 스타일
- 칭찬받고 싶은 말이 다른 이유
- 새해 계획이 무너지는 방식 (12월 말 사용)
- 쉬는 날에도 못 쉬는 이유
- 단톡방에서 나의 모습
- 거절을 못 하는 순간 / 거절하는 방식
- 화가 났을 때 나오는 행동
- 새로운 사람을 만날 때
- 공부·자격증이 작심삼일로 끝나는 이유
- 옷장 정리를 못 하는 이유 (퍼스널컬러 팔로워와 연결)
- 쇼핑할 때 실패하는 방식 (퍼스널컬러 연결)
- 책을 사 놓고 안 읽는 이유 (출간 기념회 전 사용 권장)

## 트렌드 연결
그날 뉴스·시즌·이슈(명절, 수능, 연말, 연휴, 화제의 드라마·인물 등) 중
위 형식으로 풀 수 있는 것이 있으면 후보보다 우선한다. 단, 사건·사고·정치·특정인 비난은 다루지 않는다.
